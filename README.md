# Outlier Homebrew tap

Outlier is a private AI chat and coding agent that runs entirely on your Mac (Apple silicon, macOS 15 or later).
Nothing you type leaves the Mac unless you turn on web search.

    brew install --cask outlier-host/tap/outlier

The app updates itself. To remove it: `brew uninstall --cask outlier`. Adding `--zap` also deletes `~/.outlier`, which
holds your chats and downloaded models.

More: https://outlier.host/?utm_source=homebrew-tap
